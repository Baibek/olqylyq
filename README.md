# Олқылық

Оқушының білім олқылығының **түбірін** табатын адаптивті диагностика. 9-сыныптағы қате көбіне 6-сыныптағы түсінілмеген тақырыптан басталады: жүйе 20 шақты сұрақпен бүкіл бағдарламаны тексеріп, сол түбірді және оны жабатын жеке оқу жолын көрсетеді.

EduPitch EdTech стартап жарысына арналған жұмыс істейтін MVP.

## Мүмкіндіктері

- **4 пән:** математика (алгебра, 66 тақырып), Қазақстан тарихы (41), математикалық сауаттылық (29), информатика (26). Тақырыптар мен алғышарттар ҚР үлгілік бағдарламасы негізінде.
- **Адаптивті тест:** әр жауап графтың бір бөлігін анықтайды, қате болса жүйе алғышарттарға төмен түсіп, түбірді іздейді. 300 виртуал оқушымен симуляцияда тақырыптардың 93–96%-ы дұрыс анықталады.
- **Нәтиже:** түбір олқылықтар, ата-анаға дайын хабарлама, білім картасы, апталық оқу жолы, курс пакеттері.
- **Сынып көрінісі (B2G):** мұғалімге арналған сынып бойынша жиынтық.
- **Python курсы:** 8 бөлім, 27 тапсырма. Код браузерде орындалады ([Skulpt](https://skulpt.org)), автоматты тексеріледі.
- **Видеосабақ пен Ұстаз-бот:** бейнесабақтың нақты сәтіне сұрақ қоюға болады.
- Қазақ және орыс тілдері, жарық және қараңғы тақырып, телефонға бейімделген.

> ИИ-талдау, Ұстаз-бот және дауыстап оқу claude.ai артефакт ортасының мүмкіндіктерін (`window.claude`) пайдаланады. Бет басқа жерде ашылса, бұл бөлімдер «тек claude.ai ішінде жұмыс істейді» деп хабарлайды, қалғаны толық жұмыс істейді.

## Іске қосу

Сервер, база, орнату керек емес: `index.html` файлын браузерде ашыңыз.

GitHub Pages арқылы жариялау: репозиторийде **Settings → Pages → Branch: main / root → Save**. Бірнеше минуттан кейін сайт `https://<сіздің-логин>.github.io/olqylyq/` мекенжайында ашылады.

## Құрылымы

```
index.html          дайын бет (build.py жасайды, оны тікелей өзгертпеңіз)
build.py            src/ ішінен index.html құрастырады
src/page.html       интерфейс: стильдер, мәтіндер (kk/ru), көріністер, курстар
src/engine.js       білім графтары, сұрақ генераторлары, адаптивті қозғалтқыш, симуляция
tests/check_tasks.py  Python курсының тапсырмаларын CPython-да тексереді
```

Өзгерістен кейін:

```bash
python3 build.py              # index.html қайта жасау
python3 tests/check_tasks.py  # курс тапсырмаларын тексеру
```

## Олқылық (RU)

Адаптивная диагностика, которая находит **корень** пробела в знаниях ученика: по ~20 вопросам проверяет программу 5–11 классов и строит личный маршрут, начиная с корневой темы. Четыре предмета, курс Python с выполнением кода в браузере, видеоурок с ИИ-помощником, отчёты для ученика, родителя и учителя. Запуск: откройте `index.html` в браузере или включите GitHub Pages.

# Олқылық

Оқушының білім олқылығының **түбірін** табатын адаптивті диагностика. 9-сыныптағы қате көбіне 6-сыныптағы түсінілмеген тақырыптан басталады: жүйе 20 шақты сұрақпен бүкіл бағдарламаны тексеріп, сол түбірді және оны жабатын жеке оқу жолын көрсетеді.

EduPitch EdTech стартап жарысына арналған жұмыс істейтін MVP. Бағыттар: **IELTS (A1–C1)** және 4 мектеп пәні.

**Сайт:** https://baibek.github.io/olqylyq/ · **claude.ai нұсқасы (Ұстаз-бот пен AI-талдау жұмыс істейді):** https://claude.ai/artifact/3Q87mMTUbj6NoCtm7FYvMr

## Негізгі мақсат

Оқушының немесе студенттің қай сыныпта, қай кезеңде, қай тақырыпта қалып қойғанын анықтаймыз да, сол бойынша жұмыс істейміз. Барлық тақырыпты қайталатпай, тек білмеген тақырыбын қысқа уақытта үйретеміз.

Негізгі пайдаланушы — оқу орталықтары: келген оқушының деңгейін анықтап, оны сәйкес топқа бөлу үшін.

## Мүмкіндіктері

- **5 бағыт, 209 тақырып:** IELTS / ағылшын тілі (47 тақырып, A1–C1), математика (алгебра, 66), Қазақстан тарихы (41), математикалық сауаттылық (29), информатика (26). Мектеп пәндерінің тақырыптары ҚР үлгілік бағдарламасы негізінде.
- **IELTS:** Grammar, Vocabulary, Reading және Writing дағдылары. Нәтижеде CEFR деңгейі (A1–C1) және шамамен IELTS band көрсетіледі. Listening мен Speaking тексерілмейді, сондықтан band — нақты балл емес, бағдар.
- **Адаптивті тест:** әр жауап графтың бір бөлігін анықтайды, қате болса жүйе алғышарттарға төмен түсіп, түбірді іздейді. 300 виртуал оқушымен симуляцияда тақырыптардың 93–98%-ы дұрыс анықталады.
- **Нәтиже:** түбір олқылықтар, ата-анаға дайын хабарлама, білім картасы, апталық оқу жолы, курс пакеттері.
- **Сынып көрінісі және топтарға бөлу:** сынып бойынша жиынтық; «Топтарға бөлу» батырмасы оқушыларды деңгейі бойынша топтарға бөліп (IELTS-те A1–C1, басқа пәндерде меңгеру деңгейі), әр топтың ортақ түбір олқылығын көрсетеді.
- **Python курсы:** 8 бөлім, 27 тапсырма. Код браузерде орындалады ([Skulpt](https://skulpt.org)), автоматты тексеріледі.
- **IELTS демо-сабақтары:** 3 анимациялы сабақ (Present Perfect және Past Simple, Reading: True/False/Not Given, Writing Task 1: трендтер), қазақша және орысша субтитрмен. Бейнесабақ бетінде «Математика / IELTS» ауыстырғышы бар.
- **Ұстаз-бот:** оқушының түбір олқылығын біледі, жадысы бар, «Қадамдап үйрен» және «Тест» режимдері; IELTS бағытында ағылшын тілі мұғалімі ретінде сөйлеседі.
- Қазақ және орыс тілдері, жарық және қараңғы тақырып, телефонға бейімделген.

> ИИ-талдау, Ұстаз-бот және дауыстап оқу claude.ai артефакт ортасының мүмкіндіктерін (`window.claude`) пайдаланады. Бет басқа жерде ашылса, бұл бөлімдер «тек claude.ai ішінде жұмыс істейді» деп хабарлайды, қалғаны толық жұмыс істейді.

## Іске қосу

Сервер, база, орнату керек емес: `index.html` файлын браузерде ашыңыз. Файлды мессенджер немесе «Файлдар» қолданбасы арқылы ашпаңыз: олар бетті көрсетеді, бірақ JavaScript-ті іске қоспайды, сондықтан батырмалар жұмыс істемейді.

GitHub Pages арқылы жариялау: репозиторийде **Settings → Pages → Branch: `gh-pages` / root → Save** (`gh-pages` тармағы `main`-нің көшірмесі). Бірнеше минуттан кейін сайт `https://<сіздің-логин>.github.io/olqylyq/` мекенжайында ашылады.

## Құрылымы

```
index.html          дайын бет (build.py жасайды, оны тікелей өзгертпеңіз)
build.py            src/ ішінен index.html құрастырады
src/page.html       интерфейс: стильдер, мәтіндер (kk/ru), көріністер, курстар
src/engine.js       білім графтары, сұрақ генераторлары, адаптивті қозғалтқыш, симуляция
tests/check_tasks.py  Python курсының тапсырмаларын CPython-да тексереді
tests/check_engine.mjs  графтар, сұрақтар, дәлдік, CEFR және топтар (Node)
tests/smoke.mjs     браузердегі тексеріс (Playwright)
```

Өзгерістен кейін:

```bash
python3 build.py              # index.html қайта жасау
python3 tests/check_tasks.py  # курс тапсырмаларын тексеру
node tests/check_engine.mjs   # графтар, сұрақтар, дәлдік, CEFR, топтар
node tests/smoke.mjs          # браузерде: IELTS диагностикасы, топтар, бот
```

## Олқылық (RU)

Адаптивная диагностика, которая находит **корень** пробела в знаниях ученика: по ~20 вопросам проверяет программу 5–11 классов и строит личный маршрут, начиная с корневой темы. Четыре предмета, курс Python с выполнением кода в браузере, видеоурок с ИИ-помощником, отчёты для ученика, родителя и учителя. Запуск: откройте `index.html` в браузере или включите GitHub Pages.
